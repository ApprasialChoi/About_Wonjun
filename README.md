# About Wonjun

중앙감정평가법인 본사 소속 **최원준 감정평가사** 소개 웹페이지.

원본 브로슈어(`스티커_20260604.pptx`)의 1페이지·2페이지 내용을 한 장의 `index.html`로 옮긴 것으로,
스크롤을 내리면 두 개의 전체 화면이 차례로 나타납니다.

- **첫 번째 화면** — 표지 / 신원 (PPT 1p): "진심의 가치를 믿습니다", 연락처, 학력·자격증, 카카오톡 QR
- **두 번째 화면** — 전문성 / 실적 (PPT 2p): 3가지 강점, 주요업무실적, 중앙감정평가법인 소개, 주요 평가실적

## 구성

```
index.html      단일 페이지 (CSS 인라인, 스크롤 스냅 2화면)
assets/         이미지 (인물 사진, 로고, QR, 건물 사진)
```

## 보기

`index.html`을 브라우저로 열거나, 정적 서버로 실행합니다.

```bash
python -m http.server 8000
# http://localhost:8000
```
